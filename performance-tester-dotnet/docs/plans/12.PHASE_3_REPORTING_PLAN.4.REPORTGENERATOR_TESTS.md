## Overview

The `ReportGenerator` is responsible for generating **8 JSON files per test run** that document performance test results. These files must **exactly match** the format produced by the Python implementation to ensure compatibility with comparison tools.

**8 File Types Generated:**

1. **Main Report** (`test-report-{timestamp}-{process}.json`) - Summary of all phases
2. **Events Throughput** (`test-report-{timestamp}-{process}.events-throughput.json`) - Event processing metrics
3. **API Throughput** (`test-report-{timestamp}-{process}.api-throughput.json`) - API call metrics
4. **Process Resources** (`test-report-{timestamp}-{process}.resource-metrics.json`) - Service CPU/RAM
5. **System Metrics** (`test-report-{timestamp}-{process}.system-metrics.json`) - System-wide monitoring
6. **RabbitMQ Metrics** (`test-report-{timestamp}-{process}.rabbitmq-metrics.json`) - RabbitMQ container
7. **PostgreSQL Metrics** (`test-report-{timestamp}-{process}.postgres-metrics.json`) - PostgreSQL container
8. **Chart** (`test-report-{timestamp}-{process}.chart.png`) - Visualization (handled by ChartGenerator)

**Critical Success Factors:**

- ✅ **Exact JSON structure** matching Python output
- ✅ **snake_case property names** (not camelCase or PascalCase)
- ✅ **2-space indentation** (not tabs or 4 spaces)
- ✅ **Decimal precision rules** enforced for each metric type
- ✅ **Process name sanitization** following 5-step algorithm
- ✅ **Timestamp formats** differ between main report and samples
- ✅ **Zero handling** differs for min vs average calculations
- ✅ **Sample standard deviation** (n-1, not n)

### Expected Implementation

The `ReportGenerator` should:

1. **Accept inputs:**
   - `outputDirectory` - Where to write the 8 files
   - `testReport` - Aggregated test data (from all Phase 2 slices)
   - `cancellationToken` - For async cancellation

2. **Generate files:**
   - Create timestamp string: `DateTime.UtcNow.ToString("yyyyMMdd_HHmmss")`
   - Sanitize process name: Apply 5-step algorithm
   - Generate base filename: `test-report-{timestamp}-{sanitizedName}`
   - Write 7 JSON files using `System.Text.Json` with:
     - `WriteIndented = true` (2 spaces)
     - `PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower`
     - Custom `JsonConverter<DateTime>` for timestamp formatting

3. **Apply decimal precision rules:**
   - Time in seconds: 3 decimals
   - Throughput (per sec): 2 decimals
   - CPU Percent: 2 decimals
   - Memory (MB/GB): 2 decimals
   - Percentages (CV%, success%): 1 decimal
   - Response Time (ms): 3 decimals

4. **Handle special cases:**
   - **Throughput min:** Exclude zeros (post-test measurements)
   - **Throughput avg:** Include zeros (accurate representation)
   - **Container vs Process metrics:** Different property names
     - Process: `memory_rss_mb` + `threads` field
     - Container: `memory_mb` (no threads)

### Test 6: GenerateReportAsync_ShouldCalculateStatisticsCorrectly

**Purpose:** Verify statistical calculations match Python implementation.

**Test Code:**

```csharp
[Fact]
public async Task GenerateReportAsync_ShouldCalculateStatisticsCorrectly()
{
    // Arrange
    var outputDirectory = CreateTempDirectory();

    // Create test report with known statistical values
    var samples = CreateSamplesWithKnownStatistics();
    var testReport = CreateTestReportWithSamples(samples);

    try
    {
        // Act
        await System.ReportGenerator.GenerateReportAsync(outputDirectory, testReport);

        // Assert - Read events throughput report
        var eventsThroughputPath = Path.Combine(outputDirectory,
            $"test-report-{testReport.TestDate:yyyyMMdd_HHmmss}-testservice.events-throughput.json");
        var json = await File.ReadAllTextAsync(eventsThroughputPath);
        var doc = JsonDocument.Parse(json);
        var summary = doc.RootElement.GetProperty("summary");

        // Verify calculations
        var avgRate = summary.GetProperty("avg_events_per_second").GetDouble();
        Assert.Equal(100.00, avgRate, precision: 2); // Average of sample rates

        var peakRate = summary.GetProperty("peak_events_per_second").GetDouble();
        Assert.Equal(150.00, peakRate, precision: 2); // Max of sample rates

        var minRate = summary.GetProperty("min_events_per_second").GetDouble();
        Assert.Equal(50.00, minRate, precision: 2); // Min excluding zeros

        var stdDevRate = summary.GetProperty("std_dev_events_per_second").GetDouble();
        // Verify sample standard deviation (N-1, not N)
        var expectedStdDev = CalculateExpectedStdDev(samples);
        Assert.Equal(expectedStdDev, stdDevRate, precision: 2);

        var cvRate = summary.GetProperty("cv_events_per_second").GetDouble();
        // CV = (stdDev / mean) * 100
        var expectedCv = (expectedStdDev / avgRate) * 100.0;
        Assert.Equal(expectedCv, cvRate, precision: 1);

        var avgResponseTime = summary.GetProperty("avg_response_time_ms").GetDouble();
        // Response time = 1000.0 / avg_rate
        var expectedResponseTime = 1000.0 / avgRate;
        Assert.Equal(expectedResponseTime, avgResponseTime, precision: 3);

        var totalSamples = summary.GetProperty("total_samples").GetInt32();
        Assert.Equal(samples.Count, totalSamples);

        var totalEvents = summary.GetProperty("total_events").GetInt32();
        Assert.Equal(samples.Last().CumulativeCount, totalEvents);
    }
    finally
    {
        CleanupTempDirectory(outputDirectory);
    }
}

/// <summary>
/// Creates samples with known statistical properties for testing.
/// </summary>
private static List<ThroughputSample> CreateSamplesWithKnownStatistics()
{
    return new List<ThroughputSample>
    {
        new ThroughputSample { Rate = 100.0, CumulativeCount = 10, Timestamp = DateTime.UtcNow },
        new ThroughputSample { Rate = 150.0, CumulativeCount = 25, Timestamp = DateTime.UtcNow },
        new ThroughputSample { Rate = 75.0, CumulativeCount = 32, Timestamp = DateTime.UtcNow },
        new ThroughputSample { Rate = 50.0, CumulativeCount = 37, Timestamp = DateTime.UtcNow },
        new ThroughputSample { Rate = 125.0, CumulativeCount = 50, Timestamp = DateTime.UtcNow }
    };
}

/// <summary>
/// Calculates expected sample standard deviation (N-1).
/// </summary>
private static double CalculateExpectedStdDev(List<ThroughputSample> samples)
{
    var rates = samples.Select(s => s.Rate).ToList();
    var mean = rates.Average();
    var sumSquaredDiffs = rates.Sum(r => Math.Pow(r - mean, 2));
    return Math.Sqrt(sumSquaredDiffs / (rates.Count - 1)); // N-1, not N
}
```

**Key Formulas:**
- **Average:** `sum(values) / count(values)`
- **Peak:** `max(values)`
- **Min:** `min(values where value > 0)` - excludes zeros
- **Std Dev:** Sample standard deviation (N-1, not N)
  - `sqrt(sum((x - mean)^2) / (N - 1))`
- **CV%:** `(stdDev / mean) * 100`
- **Response Time:** `1000.0 / avg_rate`

        Assert.Contains(lines, line => line.StartsWith("  \"test_date\""));

    }

/// <summary>
/// Asserts that JSON file uses snake_case property names.
/// </summary>
public static async Task HasSnakeCasePropertyNames(
    this AssertingThat<string> assertingThat,
    params string[] expectedProperties)
{
    var filePath = assertingThat.InstanceToAssert;
    var json = await File.ReadAllTextAsync(filePath);

    foreach (var property in expectedProperties)
    {
        Assert.Contains($"\"{property}\"", json);
    }
}

/// <summary>
/// Sanitizes process name for filename (5-step algorithm).
/// </summary>
private static string SanitizeProcessName(string processName)
{
    // 1. Remove file extensions
    processName = Regex.Replace(processName, @"\.(jar|dll|exe)$", "", RegexOptions.IgnoreCase);

    // 2. Replace spaces and special chars with dashes
    processName = Regex.Replace(processName, @"[^a-zA-Z0-9.-]+", "-");

    // 3. Remove consecutive dashes
    processName = Regex.Replace(processName, @"-+", "-");

    // 4. Remove leading/trailing dashes
    processName = processName.Trim('-');

    // 5. Convert to lowercase
    return processName.ToLowerInvariant();
}

## Troubleshooting

### Issue: Files not created

**Symptoms:** `GenerateReportAsync` returns successfully but no files in output directory.

**Possible Causes:**
- Output directory doesn't exist
- Insufficient permissions
- Path separators incorrect (Windows vs Linux)

**Solutions:**
- Ensure directory exists before calling `GenerateReportAsync`
- Use `Path.Combine()` for cross-platform paths
- Check directory permissions

### Issue: JSON property names incorrect

**Symptoms:** Tests fail because JSON uses camelCase or PascalCase.

**Possible Causes:**
- `JsonSerializerOptions` not configured correctly
- Using wrong serializer (Newtonsoft.Json instead of System.Text.Json)

**Solutions:**
```csharp
JsonSerializerOptions options = new()
{
    PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower,
    WriteIndented = true
};
```

### Issue: Decimal precision incorrect

**Symptoms:** Values have too many or too few decimal places.

**Possible Causes:**
- Not using `Math.Round()` before serialization
- Rounding at wrong step in calculation

**Solutions:**
- Apply `Math.Round()` after calculation, before serialization
- Use correct precision for each metric type (see plan Task 6)

### Issue: Timestamps incorrectly formatted

**Symptoms:** Sample timestamps missing timezone or using wrong format.

**Possible Causes:**
- Not using custom `JsonConverter<DateTime>`
- Using `DateTime.ToLocalTime()` instead of UTC

**Solutions:**
- Create custom `JsonConverter<DateTime>` for sample timestamps
- Always use `DateTime.UtcNow` and `DateTimeKind.Utc`
- Main report format: `testDate.ToString("yyyy-MM-dd HH:mm:ss")`
- Sample format: `timestamp.ToString("yyyy-MM-ddTHH:mm:ss.ffffffzzz")`

### Issue: Min calculation includes zeros

**Symptoms:** Min value is 0.0 when it should be higher.

**Possible Causes:**
- Not filtering zeros before calculating min

**Solutions:**
```csharp
// Correct approach
var nonZeroRates = rates.Where(r => r > 0).ToList();
var minRate = nonZeroRates.Any() ? nonZeroRates.Min() : 0.0;

// NOT this
var minRate = rates.Min(); // Includes zeros!
```

### Issue: Standard deviation incorrect

**Symptoms:** Std dev values don't match Python output.

**Possible Causes:**
- Using population standard deviation (N) instead of sample (N-1)

**Solutions:**
```csharp
// Correct: Sample standard deviation (N-1)
var stdDev = Statistics.StandardDeviation(values); // MathNet.Numerics default

// NOT this
var variance = values.Sum(v => Math.Pow(v - mean, 2)) / values.Count; // Population (N)
```

### Issue: Process name not sanitized

**Symptoms:** Filenames contain uppercase letters or special characters.

**Possible Causes:**
- Not applying all 5 sanitization steps
- Wrong order of operations

**Solutions:**
```csharp
// Correct order
public static string SanitizeProcessName(string processName)
{
    // 1. Remove file extensions (.jar, .dll, .exe)
    processName = Regex.Replace(processName, @"\.(jar|dll|exe)$", "", RegexOptions.IgnoreCase);

    // 2. Replace spaces and special chars with dashes
    processName = Regex.Replace(processName, @"[^a-zA-Z0-9.-]+", "-");

    // 3. Remove consecutive dashes
    processName = Regex.Replace(processName, @"-+", "-");

    // 4. Remove leading/trailing dashes
    processName = processName.Trim('-');

    // 5. Convert to lowercase
    return processName.ToLowerInvariant();
}
```

### Issue: Indentation is 4 spaces or tabs

**Symptoms:** JSON files have 4-space indentation or tabs.

**Possible Causes:**
- Editor settings overriding serializer settings
- Using wrong serializer

**Solutions:**
- `System.Text.Json` with `WriteIndented = true` defaults to 2 spaces
- Do NOT post-process JSON with editor formatting
- Verify with hex editor if needed
