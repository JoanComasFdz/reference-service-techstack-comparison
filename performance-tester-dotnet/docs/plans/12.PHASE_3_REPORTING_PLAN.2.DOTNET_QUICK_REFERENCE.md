This is a comprehensive guide for implementing performance test reporting in .NET to match the Python framework exactly.

## Overview

The .NET performance testing implementation must generate equivalent JSON and PNG files to the Python framework. This ensures:

- Consistent metrics across all service implementations
- Fair performance comparisons

## Key Implementation Details

### Timestamp Formatting

**Main Report Timestamp:**
```
DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss")
```

**Sample Timestamps (ISO 8601 with UTC):**
```
DateTime.UtcNow.ToString("yyyy-MM-ddTHH:mm:ss.ffffff") + "+00:00"
// or
DateTime.UtcNow.ToString("O") // ISO 8601 format
```

### Decimal Precision

Use `Math.Round()` for proper rounding:

```csharp
// Time in seconds (3 decimals)
Math.Round(value, 3)

// Throughput per second (2 decimals)
Math.Round(value, 2)

// CPU/Memory (2 decimals)
Math.Round(value, 2)

// Percentages (1 decimal)
Math.Round(value, 1)

// Response Time in ms (3 decimals)
Math.Round(value, 3)
```

### Statistical Calculations

```csharp
// Standard Deviation (sample, using n-1)
double StdDev(List<double> values)
{
    if (values.Count < 2) return 0;
    double mean = values.Average();
    double variance = values.Sum(x => Math.Pow(x - mean, 2)) / (values.Count - 1);
    return Math.Sqrt(variance);
}

// Coefficient of Variation
double CV = (stdDev / mean) * 100;

// Response Time
double responseTimeMs = (mean > 0) ? 1000.0 / mean : 0;

// Mode (round to nearest int first)
int Mode(List<double> values)
{
    var rounded = values.Select(v => (int)Math.Round(v)).ToList();
    return rounded.GroupBy(x => x)
        .OrderByDescending(g => g.Count())
        .First().Key;
}
```

### Handling Zero Values in Min Calculation

```csharp
// For throughput metrics, exclude zeros from min:
var nonZeroValues = values.Where(v => v > 0).ToList();
double min = nonZeroValues.Any() ? nonZeroValues.Min() : 0;

// For averages, include all values:
double avg = values.Average();
```

### Process Name Sanitization

```csharp
string SanitizeProcessName(string name)
{
    // Remove extensions
    name = Regex.Replace(name, @"\.(jar|dll|exe)$", "", RegexOptions.IgnoreCase);
    
    // Replace special chars with dashes
    name = Regex.Replace(name, @"[^\w\-\.]", "-");
    
    // Remove consecutive dashes
    name = Regex.Replace(name, @"-+", "-");
    
    // Remove leading/trailing dashes
    name = name.Trim('-');
    
    // Convert to lowercase
    return name.ToLower();
}
```

### File Naming

```csharp
string GetReportFilename(DateTime timestamp, string processName, string suffix)
{
    string timestampStr = timestamp.ToString("yyyyMMdd_HHmmss");
    string sanitized = SanitizeProcessName(processName);
    return $"test-report-{timestampStr}-{sanitized}.{suffix}";
}
```

### JSON Serialization Settings

```csharp
var options = new JsonSerializerOptions
{
    WriteIndented = true,           // 2-space indentation
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    NumberHandling = JsonNumberHandling.AllowNamedFloatingPointLiterals
};

string json = JsonSerializer.Serialize(data, options);
```

## Critical Success Factors

1. **Numeric Precision:** Must match Python exactly - test a few values
2. **Timestamp Formats:** Two different formats - main report vs samples
3. **JSON Indentation:** Must be exactly 2 spaces
4. **Zero Handling:** Different logic for throughput min vs overall handling
5. **Standard Deviation:** Use sample formula (n-1), not population
6. **Process Monitoring:** Must handle Java, .NET, Python, Go, Rust, Bun processes
7. **WSL2 Detection:** If detected, attempt Windows PowerShell queries
8. **Decimal Rounding:** Use proper rounding, not string truncation

```csharp
[Test]
public void ProcessName_Sanitization_RemovesExtensions()
{
    Assert.AreEqual("python", SanitizeProcessName("pythonReferenceService"));
    Assert.AreEqual("dotnet9aot", SanitizeProcessName("dotnet9AotReferenceService.exe"));

    var ts = new DateTime(2025, 11, 13, 14, 25, 30);

    Assert.AreEqual("2025-11-13 14:25:30", result);
```

## Integration with Comparison Tool

The Python comparison tool expects these files and will:

1. Look for files matching pattern: `test-report-*.json`
2. Extract timestamp and process name from filename
3. Load corresponding metrics files (resource, api, events, system)
4. Generate markdown comparison report
5. Create performance highlight summaries

Ensure your .NET implementation generates files with **identical** structure so the Python tool can read them without modification.

## Debugging Tips

1. **JSON Validation:** Use online JSON validator to ensure structure is valid
2. **Timestamp Issues:** Print both formats to verify they match specification
3. **Decimal Precision:** Compare string representations, not rounded values
4. **File Naming:** Check for spaces, case sensitivity, special characters
5. **Zero Handling:** Debug by printing all values before/after filtering
6. **Standard Deviation:** Verify using calculator with sample formula
