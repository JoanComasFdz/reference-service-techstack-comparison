# Eliminate Primitive Obsession — Phase 1: EventCount, ApiDuration, ApiWorkers

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace raw `int`/`TimeSpan?` for EventCount, ApiDuration, and ApiWorkers in `TestConfiguration` with strongly-typed value objects. Validation moves from `ValidateOptions` into factory methods returning `Result<T, TError>`.

**Architecture:** "Parse, don't validate" — each value object has a `Create()` factory returning `Result<T, TError>`. Once constructed, values are guaranteed valid. Downstream code unwraps `.Value` at boundaries where primitives are still expected. Only 3 parameters are converted in this phase; remaining parameters stay as-is.

**Tech Stack:** C# records, Dunet `[Union]` source generator, `JoanComasFdz.Result`, .NET 9

**No unit tests for value objects.** The validation logic (range checks) is trivially correct and doesn't need extra test coverage. Existing `TestCommandValidatorTests` will be updated to exercise the new parse path indirectly.

## Task 2: Create EventCount value object

**Files:**
- Create: `src/PerformanceTester.Orchestration/ValueObjects/EventCount.cs`

**Step 1: Create the value object**

```csharp
using Dunet;
using JoanComasFdz.Result;
using static Result<PerformanceTester.Orchestration.ValueObjects.EventCount, PerformanceTester.Orchestration.ValueObjects.EventCountError>;

namespace PerformanceTester.Orchestration.ValueObjects;

public sealed record EventCount
{
    public int Value { get; }
    private EventCount(int value) => Value = value;

    public static Result<EventCount, EventCountError> Create(int value) =>
        value is >= 1 and <= 1_000_000
            ? new Success(new EventCount(value))
            : new Failure(new EventCountError.OutOfRange(value));

    public override string ToString() => Value.ToString();
}

[Union]
public partial record EventCountError
{
    public partial record OutOfRange(int Value);
}
```

Design: Uses `int` (not `uint`) as underlying type — avoids casting noise at every downstream `int`-accepting API boundary. The factory guarantees 1–1,000,000.

using Dunet;

namespace PerformanceTester.Orchestration.ValueObjects;

Design: Uses `ushort` internally (1–1000 fits), but `Create` accepts `int` (what System.CommandLine parses). `ushort` → `int` widening is implicit at call sites.
