## Critical Implementation Details

### Process Name Sanitization (5-step algorithm)
```
Input: "dotnet9AotReferenceService.exe"

1. Remove extensions (.jar, .dll, .exe)
   → "dotnet9AotReferenceService"

2. Replace special chars with dashes
   → "dotnet9AotReferenceService" (no special chars)

3. Remove consecutive dashes
   → "dotnet9AotReferenceService" (no consecutive)

4. Remove leading/trailing dashes
   → "dotnet9AotReferenceService" (none)

5. Convert to lowercase
   → "dotnet9aotreferenceservice"
```

### Timestamp Formats
- **Main Report:** `yyyy-MM-dd HH:mm:ss` (e.g., "2025-11-13 14:25:30")
- **File Naming:** `yyyyMMdd_HHmmss` (e.g., "20251113_142530")
- **Sample Data:** `yyyy-MM-ddTHH:mm:ss.ffffff+00:00` (e.g., "2025-11-13T14:25:30.100000+00:00")

### Decimal Precision Rules
- **Time in seconds:** 3 decimals (e.g., 125.456)
- **Throughput:** 2 decimals (e.g., 1875.22)
- **CPU/Memory:** 2 decimals (e.g., 25.50)
- **Percentages:** 1 decimal (e.g., 100.0)
- **Response Time (ms):** 3 decimals (e.g., 9.325)

### JSON Serialization
```csharp
var options = new JsonSerializerOptions
{
    PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower,
    WriteIndented = true,  // 2-space indentation
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull
};
```

### Zero Handling
- **Min Calculation:** EXCLUDE zeros (post-test measurements)
  ```csharp
  var nonZeroValues = values.Where(v => v > 0).ToList();
  var min = nonZeroValues.Any() ? nonZeroValues.Min() : 0.0;
  ```
- **Average Calculation:** INCLUDE zeros (accurate duration representation)
  ```csharp
  var avg = values.Average();
  ```

### Resource Metrics Difference
**Process Metrics (.resource-metrics.json):**
- Property: `memory_rss_mb` (NOT `memory_mb`)
- Include: `threads` field
- Sampling: 500ms

**Container Metrics (.rabbitmq-metrics.json, .postgres-metrics.json):**
- Property: `memory_mb` (NOT `memory_rss_mb`)
- Include: NO `threads` field
- Sampling: 3000ms
