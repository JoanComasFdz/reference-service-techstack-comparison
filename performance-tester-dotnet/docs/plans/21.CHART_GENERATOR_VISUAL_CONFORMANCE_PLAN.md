## Issue 1: X-Axis Time Format (P0 - CRITICAL)

### Problem
The X-axis displays raw OLE Automation Date numbers (e.g., "46,044", "46,045") instead of human-readable time format ("11:41:40", "11:41:45").

### Root Cause
ScottPlot's default axis tick formatter displays `ToOADate()` values as numeric floats. Unlike matplotlib's `DateFormatter`, ScottPlot requires explicit custom tick formatting.

### Python Reference
```python
# Line 459
ax5.xaxis.set_major_formatter(mdates.DateFormatter('%H:%M:%S'))
ax5.xaxis.set_major_locator(mdates.AutoDateLocator())
```

### Solution
Configure a custom tick generator on the bottom axis of all plots to format OADate values as `HH:mm:ss`.

### Implementation

**File:** `ChartGenerator.cs`

**Step 1:** Add a custom tick generator class (inner class or separate file):

```csharp
/// <summary>
/// Custom tick generator that formats OADate values as HH:mm:ss time strings.
/// </summary>
private sealed class TimeTickGenerator : ScottPlot.TickGenerators.NumericAutomatic
{
    public override Tick[] Ticks
    {
        get
        {
            var baseTicks = base.Ticks;
            return baseTicks.Select(t => new Tick(
                t.Position,
                DateTime.FromOADate(t.Position).ToString("HH:mm:ss"),
                t.IsMajor
            )).ToArray();
        }
    }
}
```

**Step 2:** Apply the tick generator to the bottom axis of every plot:

In `CreateThroughputPlot()`, `CreateResourcePlot()`, and after creating each plot, add:

```csharp
plot.Axes.Bottom.TickGenerator = new TimeTickGenerator();
```

**Step 3:** Configure tick label rotation (45 degrees, right-aligned) on the bottom plot only:

```csharp
// In GenerateChartAsync(), after creating plots[4]:
plots[4].Axes.Bottom.TickLabelStyle.Rotation = 45;
plots[4].Axes.Bottom.TickLabelStyle.Alignment = Alignment.MiddleLeft;
```

### Verification
- Generate a chart and verify X-axis shows "12:57:27", "12:57:30", etc.
- Verify tick spacing is reasonable (auto-located like Python)

## Issue 2: Legend Positioning (P1 - HIGH)

### Problem
Legends are positioned inside the plot area (UpperLeft), overlapping with data. Python positions legends outside the plot to the right.

### Python Reference
```python
# Line 224 (throughput), 274 (service), etc.
ax1.legend(loc='upper left', bbox_to_anchor=(1.01, 1), borderaxespad=0, fontsize=9)
ax2.legend(..., bbox_to_anchor=(1.15, 1), ...)
```

The `bbox_to_anchor=(1.01, 1)` places the legend's upper-left corner at x=1.01 (just right of plot), y=1 (top).

### Current .NET Code
```csharp
// Line 215
plot.ShowLegend(Alignment.UpperLeft);
plot.Layout.Fixed(new PixelPadding(left: 60, right: 300, bottom: 50, top: 50));
```

The `right: 300` padding reserves space, but legend is still inside.

### Solution
ScottPlot 5 supports manual legend positioning. Use `plot.Legend.Location` and adjust padding.

### Implementation

**File:** `ChartGenerator.cs`

**Step 1:** Replace `ShowLegend(Alignment.UpperLeft)` with manual positioning:

```csharp
// Configure legend to be outside the plot area on the right
plot.Legend.IsVisible = true;
plot.Legend.Alignment = Alignment.UpperLeft;
plot.Legend.Location = new Coordinates(1.02, 0.98); // Normalized coordinates
plot.Legend.FontSize = 9;
plot.Legend.OutlineColor = Colors.Transparent;
plot.Legend.ShadowColor = Colors.Transparent;
```

**Alternative approach** if `Location` doesn't work as expected:

Use ScottPlot's `ManualLegend` feature or render legend separately:

```csharp
// After plot creation, before rendering:
var legendItems = plot.Legend.GetItems().ToList();
plot.Legend.IsVisible = false; // Hide built-in legend

// Render legend manually to the right side when combining bitmaps
```

**Step 2:** Ensure right padding is sufficient:

```csharp
plot.Layout.Fixed(new PixelPadding(left: 60, right: 350, bottom: 50, top: 50));
```

### Verification
- Legend should appear outside the plot area, to the right
- Legend should not overlap with any data or axis labels

## Issue 3: Phase Labels Missing/Incorrect (P1 - HIGH)

### Problem
Phase text labels ("Consume: 1000", "API: 5s (1w)") are not visible or incorrectly positioned.

### Python Reference
```python
# Lines 477-492
if phase1_start_time and phase2_end_time:
    mid_time = phase1_start_time + (phase2_end_time - phase1_start_time) / 2
    label = f'Consume: {num_events}' if num_events else 'Consume'
    ax1.text(mid_time, ax1.get_ylim()[1] * 0.95, label,
            ha='center', va='top', fontsize=9, color='#27ae60', fontweight='bold')
```

Key: `ax1.get_ylim()[1] * 0.95` - positioned at 95% of Y-axis max.

### Current .NET Code
```csharp
// Lines 358-363
var consumeText = plot.Add.Text(consumeLabel, consumeMidTime.ToOADate(), 0);
consumeText.OffsetY = -40; // Position near top
```

Problem: Y position is `0`, and `OffsetY = -40` moves it up by 40 pixels, but the actual Y position should be near the top of the data range.

### Solution
Calculate the Y position as 95% of the throughput subplot's Y-axis maximum.

### Implementation

**File:** `ChartGenerator.cs`

**Step 1:** Modify `AddPhaseLabels()` to accept Y-axis limits:

```csharp
private void AddPhaseLabels(Plot plot, TestReport testReport, double yMax)
{
    // ... existing code ...

    // Position at 95% of Y-axis max (like Python)
    var labelYPosition = yMax * 0.95;

    var consumeText = plot.Add.Text(consumeLabel, consumeMidTime.ToOADate(), labelYPosition);
    consumeText.LabelFontColor = ChartColors.ConsumePhase;
    consumeText.LabelFontSize = 9;
    consumeText.LabelBold = true;
    consumeText.LabelAlignment = Alignment.UpperCenter;
    // Remove OffsetY - position is now correct

    // ... similar for API label ...
}
```

**Step 2:** Call with computed Y-max after data is plotted:

```csharp
// In GenerateChartAsync(), after creating throughput plot:
var throughputYMax = plots[0].Axes.GetLimits().Top;
AddPhaseLabels(plots[0], testReport, throughputYMax);
```

**Step 3:** Add 10% headroom to Y-axis (Python line 221-223):

```csharp
// In CreateThroughputPlot(), after adding data:
var limits = plot.Axes.GetLimits();
plot.Axes.SetLimitsY(limits.Bottom, limits.Top * 1.1);
```

### Verification
- "Consume: 1000" label should appear centered between consume phase boundaries, near top
- "API: 5s (1w)" label should appear centered between API phase boundaries, near top

## Issue 5: Throughput Legend Headers Missing (P2 - MEDIUM)

### Problem
Throughput legends show "Events Avg: 254.9 (3.92ms)" but Python shows:
```
Consumed Events/sec
Events Avg: 254.9 (3.92ms)
Min: 2.0
...
```

### Python Reference
```python
# Line 177
ax1.plot(timestamps, events_per_sec, color='#2ecc71', linewidth=2, label='Consumed Events/sec')
# Line 181-183
legend_label = format_throughput_legend('Events', avg, ...)
ax1.axhline(y=avg, ..., label=legend_label)
```

Python has TWO legend entries per series:
1. Primary line: "Consumed Events/sec"
2. Average line: Stats (Avg, Min, Max, etc.)

### Current .NET Code
```csharp
// Lines 164-172
eventsScatter.LegendText = FormatThroughputLegend("Events", ...);
// Average line has no legend text
```

.NET combines everything into one legend entry.

### Solution
Separate into two legend entries per series, matching Python structure.

### Implementation

**File:** `ChartGenerator.cs`

**Step 1:** Modify throughput plotting in `CreateThroughputPlot()`:

```csharp
// Events series - primary line
var eventsScatter = plot.Add.Scatter(timestamps, rates);
eventsScatter.Color = ChartColors.EventsPrimary;
eventsScatter.LineWidth = 2f;
eventsScatter.FillY = true;
eventsScatter.FillYColor = ChartColors.EventsPrimary.WithAlpha(0.3);
eventsScatter.LegendText = "Consumed Events/sec"; // Just the label

// Events average line - with stats
var eventsAvg = plot.Add.HorizontalLine(eventsData.Summary.AvgRate);
eventsAvg.Color = ChartColors.EventsAverage;
eventsAvg.LineWidth = 1.5f;
eventsAvg.LinePattern = LinePattern.Dashed;
eventsAvg.LegendText = FormatThroughputLegend(
    "Events",
    eventsData.Summary.AvgRate,
    eventsData.Summary.AvgResponseTimeMs,
    eventsData.Summary.MinRate,
    eventsData.Summary.PeakRate,
    (int)Math.Round(eventsData.Summary.AvgRate),
    eventsData.Summary.StdDevRate,
    eventsData.Summary.CvRate);
```

**Step 2:** Same for API series:

```csharp
apiScatter.LegendText = "API calls/sec"; // Just the label
apiAvg.LegendText = FormatThroughputLegend("API", ...);
```

### Verification
- Legend should show "Consumed Events/sec" with line sample
- Below it, dashed line with "Events Avg: X.X (Y.YYms)\nMin: ...\nMax: ..."
- Same pattern for "API calls/sec"

## ScottPlot API Notes

### DateTime Axis Formatting
ScottPlot 5 uses `ITickGenerator` for custom tick formatting. Key classes:
- `ScottPlot.TickGenerators.NumericAutomatic` - base class to extend
- `Tick` struct - position, label, isMajor

### Legend Positioning
ScottPlot 5 legend positioning options:
- `plot.Legend.Alignment` - anchor point
- `plot.Legend.Location` - explicit coordinates (if supported)
- Manual rendering via `plot.Legend.GetItems()` and custom drawing

### Text Annotations
- `plot.Add.Text(label, x, y)` - adds text at data coordinates
- `LabelAlignment` - anchor point (UpperCenter for centered above point)
- Position should be in data coordinates, not pixel offsets
