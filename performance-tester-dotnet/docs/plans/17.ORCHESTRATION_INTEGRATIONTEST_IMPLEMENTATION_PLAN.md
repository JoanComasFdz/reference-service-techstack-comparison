## WS-0: Prerequisites (MUST COMPLETE FIRST)

### Task 0.1: Enhance ConfigurableReferenceService

**File:** `Infrastructure/ConfigurableReferenceService.cs`

**New Capabilities Required:**

```csharp
public class ConfigurableReferenceService
{
    // EXISTING (no changes needed):
    public void ConfigurePublication(int eventCount, int warmupEventCount = 0)
    public void ConfigureHttpResponse(int statusCode)
    public void ConfigureIntermittentFailures(int failEveryNthRequest)

    // NEW - Add these methods:

    /// <summary>
    /// Configure service to publish warmup events only, no test events.
    /// Use for testing warmup timeout scenarios.
    /// </summary>
    public void ConfigureWarmupOnly(int warmupEventCount)
    {
        _warmupEventCount = warmupEventCount;
        _testEventCount = 0;
        _publishMode = PublishMode.WarmupOnly;
    }

    /// <summary>
    /// Configure service to terminate (stop responding) after processing N events.
    /// Use for testing process death scenarios.
    /// </summary>
    public void ConfigureTerminationAfterEvents(int eventCount)
    {
        _terminateAfterEvents = eventCount;
        _terminationEnabled = true;
    }

    /// <summary>
    /// Configure delay between publishing each event.
    /// Use for testing slow processing scenarios.
    /// </summary>
    public void ConfigurePublishDelay(TimeSpan delayBetweenEvents)
    {
        _publishDelay = delayBetweenEvents;
    }

    /// <summary>
    /// Configure service to not respond to any events (complete silence).
    /// Use for testing complete timeout scenarios.
    /// </summary>
    public void ConfigureNoResponse()
    {
        _publishMode = PublishMode.NoResponse;
    }

    // Internal implementation:
    private enum PublishMode { Normal, WarmupOnly, NoResponse }
    private PublishMode _publishMode = PublishMode.Normal;
    private int _terminateAfterEvents = int.MaxValue;
    private bool _terminationEnabled = false;
    private TimeSpan _publishDelay = TimeSpan.Zero;
}
```

**Implementation Details:**

1. **WarmupOnly Mode:**
   - In `HandleIncomingEventAsync`, check if event is warmup (based on counter)
   - If `_publishMode == PublishMode.WarmupOnly`, only publish for warmup events
   - After all warmup events, stop publishing (but keep connection alive)

2. **Termination After Events:**
   - Track total events processed in `_processedEventCount`
   - When `_processedEventCount >= _terminateAfterEvents`, call `DisconnectAsync()`
   - This simulates process death

3. **Publish Delay:**
   - In `PublishEventAsync`, add `await Task.Delay(_publishDelay)` before publishing
   - Only if `_publishDelay > TimeSpan.Zero`

4. **NoResponse Mode:**
   - In `HandleIncomingEventAsync`, simply ACK without publishing
   - Service stays alive but produces no output

**Testing:**
- Verify each new method with a simple unit test
- No integration test needed for infrastructure changes

**Estimated Effort:** 2-3 hours

## Appendix A: Test Infrastructure Helpers

### Helper: Standard Test Setup Pattern

```csharp
protected async Task<TestReport> RunStandardTestAsync(
    int port,
    Action<TestConfigurationBuilder>? configure = null)
{
    var builder = new TestConfigurationBuilder()
        .WithServicePort(port)
        .WithWarmupEventCount(10)
        .WithEventCount(10)
        .WithApiDuration(TimeSpan.FromSeconds(3));

    configure?.Invoke(builder);
    var config = builder.Build();

    System.ConfigurableReferenceService.ConfigurePublication(
        eventCount: config.EventCount,
        warmupEventCount: config.WarmupEventCount);

    await System.ConfigurableReferenceService.ConnectAndSubscribeAsync(listenPort: port);
    await System.WaitForServiceHealthyAsync(port: port);

    try
    {
        return await System.Orchestration.Orchestrator.RunTestAsync(config);
    }
    finally
    {
        await System.ConfigurableReferenceService.DisconnectAsync();
        await System.RabbitMQ.PurgeQueueAsync(ConfigurableReferenceService.DefaultInputQueueName);
    }
}
```

    }
