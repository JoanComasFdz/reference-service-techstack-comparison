**Implementation Pattern:**
```csharp

var orchestrator = host.Services.GetRequiredService<ITestOrchestrator>();
await orchestrator.RunTestAsync(config, cancellationToken);
```

## Key Improvements Over Python Implementation

1. **Inactivity Timeout** (EventConsuming)
   - Python: Absolute 120s timeout from start
   - .NET: Inactivity timeout that resets on each event received
   - Benefit: Allows slow-but-progressing services to complete

2. **Real-Time k6 Parsing** (ApiLoadTesting)
   - Python: Post-process JSON file after completion
   - .NET: Stream parse JSON as k6 outputs (lower memory, immediate error detection)

3. **Type Safety**
   - Python: Dynamic typing, runtime errors
   - .NET: Nullable reference types, compile-time safety

4. **Testability**
   - Python: Monolithic script, hard to test components
   - .NET: VSA with isolated integration tests per slice

## Architecture Notes

**Vertical Slice Architecture (VSA):**
- Each slice owns its models (no central Core project)
- Producer-owned contracts
- Independent DI registration per slice
- Zero cross-slice dependencies in production code

**BackgroundService Pattern:**
- ProcessMonitorService, DockerMonitorService, EventConsumerService
- Managed lifecycle via IHost.StartAsync/StopAsync
- Channel-based producer-consumer for metrics

**Orchestration Workflow:**
1. Setup (discover service, clear DB/queues)
2. Warmup (JIT compilation, not measured)
3. Event Test (concurrent publish + consume)
4. API Test (k6 load testing)
5. Reporting (JSON + PNG + comparison)
