```csharp

var phaseAwaiter = new PhaseAwaiter();
var report = await orchestrator.RunTestAsync(config, progress: phaseAwaiter);

// Wait for specific phase (with timeout)
await phaseAwaiter.WaitForPhaseStartAsync(TestPhase.ApiTest, TimeSpan.FromSeconds(30));
await phaseAwaiter.WaitForPhaseCompleteAsync(TestPhase.ApiTest);

// Assert phase sequence

    (TestPhase.ApiTest, PhaseState.Completed));
```

#### Task A.1: Fix `RunTestAsync_WhenApiServerReturnsErrors_ShouldAbortAndReportReason`

**Location:** Lines 31-75

**Current Problematic Code (Line 64):**
```csharp

    "Should have terminated early");
```

**Problem:** Race condition - duration check is timing-dependent and can fail under load.

**Required Changes:**

1. **Remove Line 64** - Delete the duration-based assertion entirely

2. **Verify existing assertions are sufficient (Lines 59-60):**
   ```csharp

       .ApiLoadTestWasAborted(report, "consecutive failures");
   ```
   ✅ This assertion is already deterministic - keep it.

3. **Add PhaseAwaiter for phase state verification:**
   ```csharp
   // Add at line 43 (before var report = ...)
   var phaseAwaiter = new PhaseAwaiter();

   // Modify line 44 to pass phaseAwaiter
   var report = await System.Orchestration.Orchestrator.RunTestAsync(
       config,
       progress: phaseAwaiter);

   // Add after line 60 (after ApiLoadTestWasAborted assertion)
   // Verify API phase was reported as failed (not completed)
   Assert.Contains(phaseAwaiter.ReceivedPhases,
       p => p.Phase == TestPhase.ApiTest && p.State == PhaseState.Failed);
   ```

**Validation:** Test should verify abort occurred without relying on timing.

## Patterns Reference

### Pattern A: Remove Timing Assertion, Keep State Assertion

**Use when:** Test has both timing and state assertions, timing is problematic.

```csharp
// BEFORE
Assert.True(report.DurationSeconds < expected);  // REMOVE
await Asserting.That(...).WasAborted(report);    // KEEP

// AFTER
await Asserting.That(...).WasAborted(report);    // KEEP
Assert.Contains(phaseAwaiter.ReceivedPhases,     // ADD
    p => p.Phase == TestPhase.ApiTest && p.State == PhaseState.Failed);
```

### Pattern B: Replace Duration Tolerance with Phase Completion

**Use when:** Test verifies "ran for approximately X seconds."

```csharp
// BEFORE
await Asserting.That(...).DurationApproximately(report, expected, tolerance: 2s);

// AFTER
phaseAwaiter.AssertPhasesReceivedInOrder(
    (TestPhase.ApiTest, PhaseState.Starting),
    (TestPhase.ApiTest, PhaseState.Completed));
```
