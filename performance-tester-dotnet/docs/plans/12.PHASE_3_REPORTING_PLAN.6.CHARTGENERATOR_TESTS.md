## Overview

The `ChartGenerator` class generates performance visualization charts combining throughput, CPU, and RAM metrics over time. It produces PNG files with 5 subplots matching the Python implementation's exact layout, colors, and formatting.

**Critical Success Factors:**
1. **5 subplots** (not 3!) - Throughput, Service CPU/RAM, RabbitMQ, PostgreSQL, System
2. **Dual Y-axes** - CPU% (left), RAM MB (right) for all resource plots
3. **Exact color matching** - 16 specific hex colors from Python implementation
4. **Phase boundaries** - Vertical lines with labels at phase transitions
5. **150 DPI export** - PNG resolution matching matplotlib output
6. **Legend outside** - Positioned to right edge, not overlapping data

## ScottPlot 5.x Implementation Strategy

### Library Capabilities

**ScottPlot 5.x** is the recommended .NET charting library for this implementation:

**Why ScottPlot?**
- ✅ Cross-platform (Windows, Linux, macOS)
- ✅ No GUI dependencies (headless rendering)
- ✅ Supports dual Y-axes natively
- ✅ High-quality PNG export with configurable DPI
- ✅ Clean, modern API (easier than OxyPlot)
- ✅ Active development and community

**ScottPlot 5.x vs matplotlib Comparison:**

| Feature | matplotlib (Python) | ScottPlot 5.x (.NET) |
|---------|---------------------|----------------------|
| Subplot grid | `plt.subplots(5, 1)` | `Plot.ScottPlot.MultiPlot(rows: 5, cols: 1)` |
| Dual Y-axes | `ax.twinx()` | `plot.Add.LeftAxis()` / `plot.Add.RightAxis()` |
| Line plots | `ax.plot(x, y, color='#xxx')` | `plot.Add.Scatter(x, y).Color = Color.FromHex("#xxx")` |
| Fill between | `ax.fill_between(x, y, alpha=0.3)` | `plot.Add.FillY(x, y).FillColor = Color.FromHex("#xxx").WithAlpha(0.3)` |
| Average lines | `ax.axhline(y=avg, linestyle='--')` | `plot.Add.HorizontalLine(avg).LineStyle = LineStyle.Dashed` |
| Vertical lines | `ax.axvline(x=time, linestyle=':')` | `plot.Add.VerticalLine(time).LineStyle = LineStyle.Dotted` |
| Legends | `ax.legend(loc='upper left')` | `plot.Legend.Location = Alignment.UpperLeft` |
| PNG export | `plt.savefig(path, dpi=150)` | `plot.SavePng(path, width: 1400, height: 1600)` |

**NuGet Packages Required:**
```xml
<PackageReference Include="ScottPlot" Version="5.0.52" />
<PackageReference Include="SkiaSharp" Version="2.88.8" />
```

**ScottPlot Dependencies:**
- ScottPlot uses SkiaSharp for rendering (cross-platform graphics)
- No WPF/WinForms dependencies required
- Works in Docker containers (headless)

### Dual Y-Axes Pattern

**ScottPlot 5.x Dual Axis Implementation:**

```csharp
// Create main plot
var plot = new ScottPlot.Plot();

// LEFT Y-AXIS (CPU %)
var cpuScatter = plot.Add.Scatter(timestamps, cpuValues);
cpuScatter.Color = ScottPlot.Color.FromHex("#3498db");
cpuScatter.LineWidth = 2;

var leftAxis = plot.Axes.Left;
leftAxis.Label.Text = "Service CPU (%)";
leftAxis.Label.ForeColor = ScottPlot.Color.FromHex("#3498db");
leftAxis.Label.Bold = true;
leftAxis.Label.FontSize = 11;

// RIGHT Y-AXIS (RAM MB)
var ramScatter = plot.Add.Scatter(timestamps, ramValues);
ramScatter.Color = ScottPlot.Color.FromHex("#e74c3c");
ramScatter.LineWidth = 2;
ramScatter.Axes.YAxis = plot.Axes.Right; // Use right axis

var rightAxis = plot.Axes.Right;
rightAxis.Label.Text = "Service RAM (MB)";
rightAxis.Label.ForeColor = ScottPlot.Color.FromHex("#e74c3c");
rightAxis.Label.Bold = true;
rightAxis.Label.FontSize = 11;
```

**Key Points:**
- Each data series can be assigned to different Y-axes via `Axes.YAxis` property
- Left axis is default (`plot.Axes.Left`)
- Right axis must be explicitly enabled and configured (`plot.Axes.Right`)
- Axis labels colored to match data series
- Both axes independently scaled

    private ThroughputReport CreateSampleEventsThroughput(int sampleCount = 100)
    {
        var baseTime = new DateTime(2025, 1, 13, 14, 25, 30, DateTimeKind.Utc);
        var samples = new List<ThroughputSampleJson>();
        var random = new Random(42); // Fixed seed for reproducibility

        for (int i = 0; i < sampleCount; i++)
        {
            var elapsed = i * 0.1; // 100ms intervals
            var timestamp = baseTime.AddSeconds(elapsed);
            var rate = 2500.0 + random.Next(-500, 500); // ~2500 ± 500

            samples.Add(new ThroughputSampleJson
            {
                Timestamp = timestamp.ToString("o"), // ISO8601
                ElapsedSeconds = elapsed,
                ThroughputRate = rate,
                CumulativeCount = (int)(rate * (i + 1))
            });
        }

        var rates = samples.Select(s => s.ThroughputRate).ToList();

        return new ThroughputReport
        {
            TestDate = baseTime.ToString("yyyy-MM-dd HH:mm:ss"),
            SamplingIntervalMs = 100,
            Samples = samples,
            Summary = new ThroughputSummary
            {
                AvgRate = Math.Round(rates.Average(), 2),
                PeakRate = Math.Round(rates.Max(), 2),
                MinRate = Math.Round(rates.Where(r => r > 0).Min(), 2),
                StdDevRate = Math.Round(CalculateStdDev(rates), 2),
                CvRate = Math.Round(CalculateCV(rates), 1),
                AvgResponseTimeMs = Math.Round(1000.0 / rates.Average(), 3),
                TotalSamples = sampleCount,
                TotalCount = samples.Last().CumulativeCount
            }
        };
    }

    // Similar helpers for API throughput, resource metrics, etc.

    private static double CalculateStdDev(IEnumerable<double> values)
    {
        var valuesList = values.ToList();
        if (valuesList.Count < 2) return 0.0;

        var avg = valuesList.Average();
        var sumOfSquares = valuesList.Sum(v => Math.Pow(v - avg, 2));
        return Math.Sqrt(sumOfSquares / (valuesList.Count - 1)); // Sample std dev (n-1)
    }

    private static double CalculateCV(IEnumerable<double> values)
    {
        var valuesList = values.ToList();
        if (valuesList.Count < 2) return 0.0;

        var avg = valuesList.Average();
        if (avg == 0.0) return 0.0;

        var stdDev = CalculateStdDev(valuesList);
        return (stdDev / avg) * 100.0;
    }
