### PowerShellExecutor.cs ✨ NEW

**Purpose:** Shared helper for executing PowerShell commands with timeout and error handling.

**Created to address:** Code duplication between `WindowsCpuQuery` and `WindowsMemoryQuery`.

**Features:**
- Centralized process execution logic
- Proper timeout handling with linked `CancellationTokenSource`
- Structured `ExecutionResult` record with Success, Output, Error, and ExitCode
- Comprehensive exception handling (returns null on failure instead of throwing)
- Optional logging support

**Implementation:**
```csharp
internal static class PowerShellExecutor
{
    public sealed record ExecutionResult(bool Success, string Output, string Error, int ExitCode);

    public static async Task<ExecutionResult?> ExecuteAsync(
        string command,
        int timeoutSeconds,
        CancellationToken cancellationToken = default,
        ILogger? logger = null);
}
```

## Architecture Observations

### Testability Concern

The static classes (`PowerShellHelper`, `WindowsCpuQuery`, `WindowsMemoryQuery`) are difficult to mock in unit tests.

**Current Design:**
```csharp
// Hard to test in isolation
var cpu = await WindowsCpuQuery.QueryAsync(cancellationToken, logger);
```

**More Testable Alternative:**
```csharp
// Interface-based
public interface IWindowsMetricsQuery
{
    Task<double?> QueryCpuAsync(CancellationToken ct);
    Task<WindowsMemoryInfo?> QueryMemoryAsync(CancellationToken ct);
}

// Inject into SystemMonitorService
public SystemMonitorService(
    TimeSpan samplingInterval,
    IWindowsMetricsQuery windowsMetrics,  // Mockable
    ILogger<SystemMonitorService> logger)
```

### Logging Inconsistency

Different components handle logging differently:
- `PowerShellHelper` - No logging
- `WindowsCpuQuery` - Takes `ILogger?` as method parameter
- `WindowsMemoryQuery` - Takes `ILogger?` as method parameter
- `SystemMonitorService` - Uses constructor-injected `ILogger<T>`

**Recommendation:** Consider consistent dependency injection throughout, or document the intentional differences.
